# rss-react-course-2025

This repository contains my completed tasks from the [RS School React course](https://github.com/rolling-scopes-school/tasks/blob/master/react/README.md).

The course is designed for students who have passed Stage #2 and newcomers with experience in JavaScript, TypeScript, Git, NPM, CSS, HTML, and API interaction.

### About the Course

- Duration: 8 weeks + 3 weeks for final project
- Time commitment: 20-40 hours per week
- Main topics: React, Hooks, Routing, State Management (Redux), SSR (Next.js), Forms, Performance, and more

### Course Structure

- Weekly theory and practical tasks
- Regular reviews and feedback
- Final technical interviews

### How to Get Started

1. Clone the repository:

```
git clone https://github.com/MilaSem/rss-react-course-2025.git
```

2. Navigate into the project directory:

```
cd rss-react-course-2025
```

3. Install dependencies:

```
npm install
```

### Main Scripts

- `npm run dev` — start development server with Vite
- `npm run build` — build production version
- `npm run lint` — lint code with ESLint
- `npm run format:fix` — format code with Prettier
- `npm run test` — run tests with Vitest
